|Overview|

This homelab was built to gain hands-on experience with real-world IT systems, networking, hardware,
virtualization, and troubleshooting. It serves as a learning environment where I can safely build,
test, break, and improve technology outside of production environments.

|Purpose|

Develop practical IT skills through hands-on projects
Learn networking, routing, VLANs, and security concepts
Build and upgrade computer hardware
Practice operating system installation and system administration
Explore virtualization and isolated test environments
Deploy self-hosted services such as DNS filtering
Improve troubleshooting and problem-solving abilities
Create experience relevant to IT support, infrastructure, and cybersecurity roles

|Current Projects|

Custom-built PC systems and hardware upgrades
OPNsense router and segmented home network
Managed switch and mesh Wi-Fi deployment
Raspberry Pi running AdGuard Home
Virtual machines using VirtualBox
Rack-mounted lab infrastructure with UPS and cable management
Cybersecurity practice through picoCTF

|Goal|

Continue expanding technical knowledge through practical projects while building experience that
translates directly into real IT environments.
